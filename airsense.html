How it works

From browser tab to running firmware

No PlatformIO, no Arduino IDE, no drivers beyond what your browser already has.

🔌

1. Plug in over USB

Connect the Gateway (CYD) or Sensor Node (ESP32-C3) and click its Install button below.

🖥️

2. Pick the port

Choose the device's serial port when Chrome prompts you, then let it flash — a couple of minutes.

📶

3. Provision it

Gateways set up over a WiFi captive portal; Sensor Nodes pair automatically over ESP-NOW, no typing required. See Provisioning reference.

Air Sense Sensor Node

Always-on room monitor: samples temperature, humidity, eCO₂, and TVOC every few seconds and broadcasts a lightly-averaged reading to the Gateway over ESP-NOW. Mains/USB powered — no sleep, so the gas sensor stays warmed up.

After flashing

Provisioning reference

Gateway

On first boot (or after a BOOT-hold reset), the Gateway opens a WiFi access point:

  1. Connect a phone/laptop to AirSense-Setup-XXXXXX
  2. The captive portal opens automatically — enter the facility WiFi credentials and the tenant's ingest secret
  3. It reboots onto that network and starts forwarding readings

Hold the BOOT button for 3s at power-up to reopen the portal and reconfigure a unit already in service.

Sensor Node

No WiFi radio — pairs with the Gateway automatically over ESP-NOW, nothing to type in:

  1. Power it on while the Gateway's pairing window is open (open automatically for a few minutes after every Gateway boot, or reopened anytime with a quick tap of its button)
  2. It finds the Gateway and joins within moments, self-assigned a MAC-derived device ID (e.g. node-A1B2C3) — no manual Gateway address or channel entry
  3. It shows up under "Newly Detected" on the dashboard's Devices page — name it and assign it to a room from there

Optional: a USB serial console at 115200 baud offers help, show (current pairing status), set deviceid <value> (rename without re-pairing), and pair (force a fresh pairing search — same effect as holding BOOT for 3s at power-up).
