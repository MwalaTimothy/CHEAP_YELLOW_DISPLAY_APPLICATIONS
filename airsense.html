How it works

From browser tab to running firmware

No PlatformIO, no Arduino IDE, no drivers beyond what your browser already has.

🔌

1. Plug in over USB

Connect the Gateway (CYD) or Sensor Node (ESP32-C3) and click its Install button below.

🖥️

2. Pick the port

Choose the device's serial port when Chrome prompts you, then let it flash — a couple of minutes.

📶

3. Provision it

Gateways set up over a WiFi captive portal; Sensor Nodes over a serial command window. See Provisioning reference.

Air Sense Sensor Node

Always-on room monitor: samples temperature, humidity, eCO₂, and TVOC every few seconds and broadcasts a lightly-averaged reading to the Gateway over ESP-NOW. Mains/USB powered — no sleep, so the gas sensor stays warmed up.

After flashing

Provisioning reference

Gateway

On first boot (or after a BOOT-hold reset), the Gateway opens a WiFi access point:

  1. Connect a phone/laptop to AirSense-Setup-XXXXXX
  2. The captive portal opens automatically — enter the facility WiFi credentials and the tenant's ingest secret
  3. It reboots onto that network and starts forwarding readings

Hold the BOOT button for 3s at power-up to reopen the portal and reconfigure a unit already in service.

Sensor Node

No WiFi radio — configuration happens over USB serial at 115200 baud:

  1. Open a serial monitor; the node prints its pairing code (AS-XXXXXX) and a 5-minute config window
  2. set deviceid ward1_sensor_02, set gateway AA:BB:CC:DD:EE:FF, set channel 11
  3. save to persist and continue boot — or let the window time out to keep prior values

Same settings can be re-opened any time by holding BOOT for 3s at power-up.

Having trouble flashing? Make sure no other program (Arduino IDE, PlatformIO monitor, etc.) has the serial port open, and try a different USB cable/port if the device isn't detected. Gateway and Sensor Node firmware share this page but are separate installs — flashing one never touches the other.
